# CTF Writeups

A collection of my **Capture The Flag (CTF) writeups, solutions, notes, and scripts**.

This repository documents my hands-on practice in cybersecurity through CTF challenges, with a focus on understanding the underlying concepts and methodologies rather than simply obtaining flags.

The repository may include challenges involving:

* 🌐 Web Security
* 🔬 Reverse Engineering
* 💥 Binary Exploitation
* 🔐 Cryptography
* 🕵️ Digital Forensics
* 🌐 Networking
* 🚗 Automotive / CAN Security
* 🐧 Linux
* 🔎 OSINT
* 🧩 Miscellaneous

## ✍️ Writeups

Each writeup aims to document the complete solving process, including:

* Challenge overview
* Initial reconnaissance and observations
* Analysis and methodology
* Vulnerability or underlying mechanism
* Tools and techniques used
* Scripts and automation where applicable
* Step-by-step solution
* Key takeaways

The goal is to make the writeups useful not only as solution references, but also as learning material.

## 🛠️ Tools & Technologies
